1. Responsable du traitement

Le responsable du traitement est Oubey Ourzikene, entrepreneur individuel exerçant sous le nom commercial OZ Vizion (marque OZ Lead), SIRET 131 864 506 00012, joignable à direction@ozvizion.fr.

2. Données collectées

  • Via le formulaire « Être rappelé » : votre prénom et votre numéro WhatsApp.
  • Lors de nos échanges : le nom de votre entreprise, si vous nous le donnez, et le contenu de vos messages WhatsApp.

3. Pourquoi, et sur quelle base

But : vous recontacter au sujet de votre demande.

Base légale : votre demande. Vous nous contactez ou vous demandez à être rappelé ; nous traitons vos données pour y répondre.

4. Durée de conservation

Vos données sont conservées 3 ans après notre dernier échange, puis supprimées.

5. Destinataires

Vos données sont destinées à OZ Vizion uniquement. Elles transitent par des prestataires techniques nécessaires au service :

  • GitHub, pour l’hébergement du site ;
  • FormSubmit, pour la transmission du formulaire par e-mail ;
  • WhatsApp, pour nos échanges ;
  • IONOS, pour la messagerie e-mail.

Certains de ces prestataires peuvent traiter des données hors de l’Union européenne, dans le cadre des garanties prévues par le RGPD. Aucune donnée n’est revendue.

6. Vos droits

Vous disposez d’un droit d’accès, de rectification, d’effacement et d’opposition sur vos données. Pour l’exercer, écrivez à direction@ozvizion.fr.

Vous pouvez aussi adresser une réclamation à la CNIL : cnil.fr.

7. Cookies

Le site ne dépose aucun cookie de mesure d’audience ni de publicité. Les polices de caractères sont hébergées sur le site lui-même : aucune donnée n’est envoyée à un service de polices tiers.
